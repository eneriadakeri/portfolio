# Eneriada Keri — Developer Portfolio

A bilingual portfolio website for a junior Front-End and WordPress Developer based in Greece. The experience presents selected projects, technical skills, education and internship experience in English and Greek.

## Highlights

- English and Greek language switcher
- Responsive layout for desktop, tablet and mobile
- Front-end and WordPress-focused professional positioning
- Selected project, profile, skills, education and contact sections
- Accessible navigation and reduced-motion support
- Custom visual identity and profile portrait

## Built with

- TypeScript
- React
- Next.js
- CSS
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

For a production build:

```bash
npm run build
npm start
```

## Main files

```text
app/page.tsx                         Page content, sections and language switcher
app/globals.css                     Visual system and responsive styling
app/layout.tsx                      Metadata and global page layout
public/eneriada-keri-profile.png    Profile portrait
public/favicon.svg                  Custom EK favicon
```

## Editing the portfolio

The English and Greek text, project entries and skills are stored in the `copy` object near the top of `app/page.tsx`. Global colors and layout rules are defined in `app/globals.css`.

This portfolio is actively being developed. Project screenshots, live URLs and expanded case studies will be added as the work is finalized.
